# 版本記錄

## 3.0.1 - 2026-11-19

- 整理老師設定版面，按注視時間、語音、姓名及本區天氣分組。
- 為本區天氣選單補充預設行為和手動播報說明，並加入介面與說明文字測試。
- 改善窄螢幕設定面板和報告按鈕排版，加入手機尺寸版面測試。
- 更新 V3 使用指南、全站測試紀錄和首頁文件索引。

## 3.0.0 - 2026-11-19

- 加入老師天氣選單，預設使用天文台資料；老師選擇本區天氣時改用手動狀況播報。
- 手動選擇天氣時不依賴天文台 API，天文台資料過期或無法讀取時仍可播報，畫面會標示資料來自老師選擇。
- 加入手動天氣選擇測試，並調整手機版教師設定版面。
- 建立獨立的 V3 頁面，保留 V2 及 1.x 頁面。

## 2.0.2 - 2026-11-19

- 使用香港天文台的天氣圖示專屬更新時間顯示日期及判斷資料是否為今天，避免以較新的整體更新時間誤判舊天氣圖示。
- 加入測試，確認整體更新時間與圖示更新時間不一致時仍會採用正確時間。
- 將天氣播報改為簡短、直接的香港廣東話，並保留大雨和雷暴等天氣的安全提醒。
- 更新各天氣狀況的播報測試。
- 更新專案版本、發布說明和從 2.0.1 標籤還原的操作指引。

## 2.0.1 - 2026-11-16

- 報告同學姓名改為選填；留空亦可正常報告天氣。
- 播報前按香港時間加上「早晨」、「午安」或「晚安」；有輸入姓名時直呼名字，不再加「同學」。
- 更新不同時段問候語、姓名留空和天氣播報的自動測試。

## 2.0.0 - 2026-11-16

- 建立獨立新版，不更改原有 1.x 頁面。
- 加大眼動操作按鈕，縮小狀態文字和時間顯示區域。
- 顯示天氣資料日期和香港時間；遇到非今天資料時暫停播報並提示老師核對。
- 加入報告同學姓名，播報時先自我介紹。
- 加入按天文台天氣圖示選用的原創童趣廣東話報告語句。
- 保留凝視時間、男／女聲偏好和語音試聽。
- 加入 Playwright 自動測試及 GitHub Actions 測試工作流程。
