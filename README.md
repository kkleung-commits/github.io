# 尋找開與關 - 特教課室眼動互動遊戲

這是一個以香港粵語為主、適合特教課室使用的互動遊戲原型，重點是讓學生透過「開關」概念、聲音提示與簡單互動，練習觀察、辨識與操作。

## 目標

- 讓學生在課室情境中理解「開 / 關」概念
- 提供高對比黑底設計，適合特教場景
- 支援觸控與模擬眼動停留（dwell）互動
- 提供廣東話語音與教具音效
- 以 iPad 為主要使用裝置，優化觸控與視覺顯示

## 功能

- 自由探索模式：點擊或觸控物件切換開關狀態
- 任務挑戰模式：依指示找出目標物件並完成開/關任務
- 音效與語音導覽：以廣東話說明狀態
- 注視停留設定：支援 0.8s / 1.2s / 2.0s / 手動點擊
- 教師設定：選擇課堂可用物件及簡單／標準／挑戰難度
- 學習統計：本機記錄遊戲次數、答對率、錯誤次數與平均完成時間，可匯出 CSV 或清除
- 黑底高反差 UI：適合作為特教白板或投影展示用途
- iPad 相容：優化 viewport、safe-area、touch 事件與手勢體驗

## 啟動方式

1. 開啟網站首頁 `index.html`，或直接前往 GitHub Pages 網址。
2. 點擊「點擊開始遊戲」以啟用音效及語音。
3. 可選擇自由探索或任務挑戰模式。
4. 使用觸控或模擬眼動停留來操作物品。

原有的巴士到站頁面已保留為 `bus.html`。

## iPad 採用重點

- 支援 Safari / iPadOS 用戶體驗
- 加入 safe-area 和視窗尺寸調整
- 修正 touch / pointer 事件重疊問題

- 語音觸發加入容錯，降低 iPad Safari 啟動失敗風險

## 已知限制

- 目前仍屬模擬眼動互動，不是實際 Tobii 硬體接線
- 語音與音效依賴瀏覽器支援能力
- 統計只保存在目前瀏覽器，不會跨裝置同步，亦不記錄學生姓名
- 適合先作為新功能原型與展示用於教學場景測試
